# pixel-asset-master-skills
pixel-asset-master-skills 是一套2D 像素游戏资产生成专业技能体系与标准化工作流框架。 内置完整流水线规范、多角色协作执行机制、项目目录规约、像素尺寸 / 配色板 / 精灵模板库，集成项目初始化、风格选定、参数六维确认、像素素材生成、帧动画序列制作、资产质检、后处理、精灵图集打包与多格式导出全链路能力。 包含配套 Python 工具脚本、标准化模板库、独立工作流及严格的执行约束规则，可统一规范角色精灵、地图瓦片、道具图标、UI 组件、特效序列帧、背景场景等像素资产的生产流程，适配 Unity、Godot 等主流游戏引擎，为 AI 像素美术批量创作、个人 / 团队游戏资产生产提供可落地的标准化技能架构与工程规范。
