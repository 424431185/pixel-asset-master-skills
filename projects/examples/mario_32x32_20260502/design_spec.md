# NES Mario Walk — Design Specification

## Project Overview

NES 风格马里奥走路序列帧，32×32 像素，4 方向。

## Character Design

- **身份**: 经典马里奥，红帽蓝工装裤
- **风格**: NES 8-bit，硬边像素风，黑色描边
- **朝向**: 4-dir（下/上/左/右）

## Visual Elements

| 部位 | 设计 |
|------|------|
| 帽子 | 红色，圆弧形 |
| 头发 | 棕色，侧分 |
| 面部 | 肤色，黑眼 |
| 上衣 | 红色短袖 |
| 工装裤 | 蓝色背带裤，黄色纽扣 |
| 手套 | 白色 |
| 鞋 | 棕色 |

## Color Palette

| 用途 | 色值 | 说明 |
|------|------|------|
| 红 | #C82828 | 帽子、上衣 |
| 蓝 | #2828A0 | 工装裤 |
| 肤 | #F0C8A0 | 皮肤 |
| 白 | #FCFCFC | 手套 |
| 黑 | #000000 | 描边 |
| 棕 | #A05028 | 头发、鞋 |

## Actions

| 动作 | 方向 | 帧数 | 说明 |
|------|------|------|------|
| walk | down | 3 | 朝下走路 |
| walk | up | 3 | 朝上走路 |
| walk | left | 3 | 朝左走路 |
| walk | right | 3 | 朝右走路 |
